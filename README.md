# EVEVEIL Website

Public presentation page for the **EVEVEIL** official landing site.

Live site: [https://eveveil.com](https://eveveil.com)

## About

EVEVEIL is a dark cinematic music project built around the release **Where Secrets Bloom**.

The website was created as a minimal artist landing page with a restrained editorial mood, custom visual identity, album presentation, platform links, lyrics modal interactions, contact details, and GitHub Pages deployment on a custom domain.

## Project Scope

The public website includes:

- cinematic hero section with looping background video;
- custom EVEVEIL visual assets and logo system;
- current release presentation;
- streaming platform links;
- interactive track list with lyrics previews and modal lyrics view;
- management/contact footer;
- custom domain deployment at `eveveil.com`.

## Technical Summary

The production site was built with:

- Next.js;
- TypeScript;
- Tailwind CSS;
- Framer Motion;
- static export;
- GitHub Pages;
- custom Namecheap domain configuration.

## Repository Note

This repository is a public presentation/case-study repository only.

The private source repository contains the implementation files, working assets, development history, and deployment configuration. It is kept private to protect the project source while leaving a public reference visible on GitHub.
